# 株式会社ゆだや - バーチャル店舗統合OS (vcv)

あつまれ どうぶつの森風の温かみのあるUIで、自律AIエージェントと協調稼働する店舗統合管理プラットフォーム。

## 主な機能
- **店舗フロア稼働マップ**: 4エリア（事務所、厨房、レジカウンター、じい君の縁側）
- **自律アバター**: 店長AI、厨房AI、リーダーAI、じい君
- **タスクカンバン**: 未着手 / 実施中 / 点検中 / 要代表承認 / 完了
- **Human-in-the-Loop**: 湯田代表による承認ゲーティング（朱肉スタンプ印）
- **自作アプリ棚**: シフト管理、FF調理・廃棄、金庫・レジ引継ぎ、金券管理
