# 株式会社ゆだや - バーチャル店舗統合OS (vcv)

あつまれ どうぶつの森風の温かみのあるUIで、自律AIエージェントと協調稼働する店舗統合管理プラットフォーム。

## 主な機能
- **店舗フロア稼働マップ**: 4エリア（事務所、厨房、レジカウンター、じい君の縁側）
- **自律アバター**: 店長AI、厨房AI、リーダーAI、じい君
- **タスクカンバン**: 未着手 / 実施中 / 点検中 / 要代表承認 / 完了
- **Human-in-the-Loop**: 湯田代表による承認ゲーティング（朱肉スタンプ印）
- **自作アプリ棚**: シフト管理、FF調理・廃棄、金庫・レジ引継ぎ、金券管理
- **端末間の受け渡し**: 店用スマホで操作するアプリはタッチするとQRコードを表示。
  タブレットで完結するアプリは今まで通り画面内で開く（`APP_REGISTRY` の `device` で出し分け）

## データの保存先（3層構造）
保存処理は `src/storage/` に集約してあり、画面側のコードは保存処理を持ちません。
ストアを差し替えるだけで保存先が入れ替わります。

| ストア | 保存先 | 使われる場面 |
|---|---|---|
| `storage/local.js` | 端末内 (localStorage) | 体験版。Firebase には一切アクセスしない |
| `storage/firebase.js` | Cloud Firestore | 代表がログインしている時のみ |

体験版のデータはブラウザのデータ消去で失われるため、ヘッダーの
**💾 データ**から JSON ファイルへの書き出し・読み込みができます。
本番DBへの一括取り込みは既存データを壊すため許可していません（書き出しのみ）。

## ホーム画面に追加（PWA）
`manifest.json` と `sw.js` により、スマホ・タブレットの「ホーム画面に追加」で
アプリのように起動できます。アプリストアは使いません。

- 画面遷移は**ネットワーク優先**。更新を配信したら次の起動で反映されます
- Firebase / Firestore と自作アプリの通信は**一切キャッシュしません**
  （古いデータを掴んだまま同期できているように見える事故を防ぐため）
- QRライブラリと Firestore ストアは先読みしません。体験版の来訪者に
  余計な通信を発生させないためで、初めて使った時にキャッシュされます
- リリース時は `sw.js` の `CACHE_VERSION` を上げてください
- 不具合時の取り外しは DevTools → Application → Service Workers → Unregister

## QRコードについて
QRに載せるのは公開済みの GitHub Pages の URL のみです。
認証情報・トークン・店舗情報は一切含みません。読み取った端末側では
従来どおりログインが必要なため、QR 自体は秘密情報ではありません。
